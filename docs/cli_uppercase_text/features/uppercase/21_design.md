## 関数詳細

### `uppercase`

- 役割: 入力された1件の文字列を、Python の `str.upper()` 相当で大文字へ変換して返す（REQ-001）。空文字列 `""` を入力として許可し、`""` を返す（REQ-002）
- 入力: `text: str`（str型の文字列を1件。空文字列を含む）
- 出力: `str`（大文字変換後の文字列）
- エラー扱い: 今回は対象外。入力が文字列以外の場合の挙動は定義しない（`20_spec.md` のエラー扱いをそのまま踏襲）
- 実装時の注意点: `text.upper()` の戻り値をそのまま返すだけのシンプルな実装とする。CLI引数解析・標準出力・ファイル入出力を持たない
