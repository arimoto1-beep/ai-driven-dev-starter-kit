# 考えたことと採用した判断

## 1. AGENTS.mdは「全部を書く場所」ではなく入口にする

一番大きな判断は、AGENTS.mdを詳細ルールの正本にし続けないことだった。

AGENTS.mdには、

- ルール体系の読み方
- どこを常時読むか
- taskの必須参照ルールをどう扱うか
- 矛盾したときに勝手に解釈しないこと

くらいを置き、詳細は別ファイルへ移す。

これならAGENTS.mdは薄く保てる。

重要なのは「短くなったこと」より、**AGENTS.mdの責務が限定されたこと**だった。

## 2. core / project / task に分ける

ルールをどの単位で分けるかはかなり重要だった。

単に「共通ルール」「個別ルール」だけでも整理できるが、実際にはtask固有の手順もある。

そこで、

- core: 汎用原則、安全、承認、正式文書、変更安全性
- project: スターターキット固有の運用
- task: そのpromptでだけ必要な具体手順

という3層にした。

この分け方にした理由は、将来別プロジェクトへ持っていける部分と、このスターターキット固有の部分を混ぜたくなかったから。

また、task固有の手順が上位ruleを書き換えるような構造にもしたくなかった。

## 3. taskが読むrule一覧はpromptに持たせる

ここは今回かなり重要な判断だった。

「AIはAGENTS.mdから必要なruleを自分で探す」でも動く可能性はある。

しかし、その方式だとtaskごとに参照が揺れる。

そこで、各promptに `## 必須参照ルール` を置き、

> このtaskではこれを読む

を明示することにした。

これにより、

- rule本文の正本は `docs/rules/`
- taskが読むrule一覧の正本はprompt

という役割が分かれた。

## 4. project/00を常時読む索引にする

project固有のruleが増えると、その一覧をどこで把握するかが必要になった。

そこで `project/00_project_policy.md` をproject設定の索引として常時読む形にした。

AGENTS.mdからproject/00へ入り、task側は必要なruleを追加で読む。

「入口を薄くした結果、どこを見れば全体が分かるか分からない」という状態を避けたかった。

## 5. 矛盾時に自動で優先順位を決めない

core / project / task の層を作ると、「どれが強いか」を定義したくなる。

ただ、単純に「具体的なtaskが優先」や「後から書いた方が優先」にすると、下位promptが安全ルールを実質的に上書きできてしまう。

そこで、

- projectはcoreを弱めない
- taskはcore/projectを再定義しない
- 矛盾して読める場合はAIが勝手に解釈せず人間へ戻す

とした。

自動で賢く解釈してもらうより、**境界で止まれること**を優先した。

## 6. AGENTS.mdを各promptの参照一覧に入れない

これは最初は少し迷った。

AGENTS.mdは重要なので、全部のpromptに「AGENTS.mdを読む」と書いておいた方が安全にも見える。

ただ、AGENTS.mdはそもそも共通入口として別経路で読むもの。

各promptの `## 参照するファイル` にAGENTS.mdまで入れると、

- 共通入口
- rule
- template
- task資料

の役割がまた混ざる。

そのため通常promptからAGENTS.md参照を外した。

この変更は見た目には小さいが、「入口」と「taskの参照資料」を分けるための判断だった。

## 7. review結果とGO/STOPを分ける

レビュー結果と工程遷移判定が混ざると、「軽微な指摘ありだから進めないのか」「レビューOKなら自動的に実装していいのか」が曖昧になる。

そこで、

レビュー結果:
- OK
- 軽微な指摘あり
- 要修正
- 要仕様確認

工程判定:
- GO
- 条件付きGO
- STOP

を分けた。

これはAGENTS.md薄型化そのものとは少し横の話だが、ルール体系を整理する中で「何の判断なのか」を分離する考え方の一例になった。

## 8. 人向け説明は必要だが正本にはしない

README、overview、tutorialを消す気はなかった。

人間が使うには、一覧や説明がないと分かりづらい。

ただし、詳細ルールをそこへコピーしすぎると、変更時に追随漏れが起きる。

そのため、

> 人向け文書は地図  
> rule本文は正本

という関係にした。

後のレビューで古い説明が残ったことを考えると、この判断は必要だった。
