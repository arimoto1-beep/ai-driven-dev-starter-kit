# docs/context/work_notes（作業メモ）

このディレクトリには、作業の経緯、判断、手戻り、現在地を後から確認するための作業メモがあります。

各サブディレクトリが1つの作業テーマに対応します。サブディレクトリ内の `README.md` が、その作業の目的・現在地・付随ファイルを確認する入口です。詳しい経緯は、同じディレクトリ内の付随ファイルに分けて記録されています。

## どこから読むか

- 引き継ぎ元や確認対象として指定された作業メモがある場合は、そのサブディレクトリの `README.md` から読みます。
- 作業メモの作成・更新に使うtaskは、[`prompts/prepare_work_note.md`](../../../prompts/prepare_work_note.md) を参照してください。
- 旧方式の記録を確認する場合は、[`../ai_work_logs/README.md`](../ai_work_logs/README.md) を参照してください。
- `docs/context/` 全体の案内は、[`../README.md`](../README.md) を参照してください。

## 位置づけと運用の正本

保存場所、命名、READMEの構成、付随ファイル、作成条件、参照範囲、更新方法の詳細は、このREADMEではなく次の正本にあります。

- 作業メモに共通する原則: [`docs/rules/core/60_work_notes.md`](../../rules/core/60_work_notes.md)

- 正式資料と補助記録の関係: [`docs/rules/core/40_official_docs_and_context.md`](../../rules/core/40_official_docs_and_context.md)
- READMEのひな形: [`docs/templates/work_note_readme_template.md`](../../templates/work_note_readme_template.md)
