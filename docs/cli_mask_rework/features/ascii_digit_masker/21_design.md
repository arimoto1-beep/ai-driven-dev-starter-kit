## 関数詳細

### `mask_ascii_digits`

- 役割: 入力文字列に含まれる ASCII 数字 `0`〜`9` を、それぞれ1文字の `*` に置換する（REQ-001）。ASCII数字以外の文字は、文字・順序・個数を変更せず保持する（REQ-002）。空文字列 `""` を有効な入力として受け取り、`""` を返す（REQ-003）。全角数字（例: `１`）やその他の Unicode 数字は置換対象にしない（REQ-004）
- 入力: `text: str`（str型の文字列を1件。空文字列、ASCII以外のUnicode文字を含んでよい）
- 出力: `str`（入力と同じ文字数。ASCII数字だけが `*` に置き換わり、それ以外は入力と同一の文字を同じ位置に保持する）。標準出力は行わない（REQ-005）
- エラー扱い: 今回は対象外。`str` 以外が渡された場合の型チェックや独自例外は定義しない（`20_spec.md` のエラー扱いをそのまま踏襲）
- 実装時の注意点:
  - 1文字ずつ走査し、ASCII数字（コードポイントとして `'0'` 以上 `'9'` 以下）かどうかを判定して置換する
  - `str.isdigit()` / `str.isnumeric()` は全角数字や他のUnicode数字も真になるため、ASCII数字だけを判定する用途では使わない（REQ-004）
  - 外部ライブラリは使用しない（REQ-006）
