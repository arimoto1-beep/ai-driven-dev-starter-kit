## 正常系

- TV-001: 英数字混在の文字列で、ASCII数字だけが `*` に置換され、それ以外は保持される
- TV-002: ASCII数字だけの文字列で、すべての文字が `*` に置換される
- TV-003: ASCII数字を含まない文字列で、入力がそのまま返る
- TV-005: 全角数字・Unicode数字を含む文字列で、それらは置換対象にならない
- TV-006: 戻り値の型が `str` であり、標準出力を行わない

## 異常系

- 該当なし。`20_spec.md` の「エラー扱い」により、`str` 以外の入力に対する型チェックや独自例外は今回の対象外と明記されているため、異常系のテスト観点は設けない

## 境界値

- TV-004: 空文字列 `""` を渡すと `""` が返る
