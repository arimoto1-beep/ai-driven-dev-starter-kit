# 機能名

ascii_digit_masker

## 作りたいもの

入力文字列に含まれる ASCII 数字 `0`〜`9` だけを `*` に置換し、その他の文字をそのまま保った文字列を返す feature を作ります。

feature は文字列変換だけを担当し、CLI引数解析や標準出力は担当しません。

## 実行イメージ

```text
mask_ascii_digits("A1B23") -> "A*B**"
```

## 期待する出力

```text
A*B**
```

## 必須要件

- REQ-001: 入力文字列中の ASCII 数字 `0`〜`9` を、それぞれ1文字の `*` に置換する。
- REQ-002: ASCII 数字 `0`〜`9` 以外の文字は、文字・順序・個数を変更せず保持する。
- REQ-003: 空文字列を有効な入力として受け取り、空文字列を返す。
- REQ-004: 全角数字（例: `１`）やその他の Unicode 数字は置換対象にしない。
- REQ-005: feature は変換結果を `str` として返し、標準出力を行わない。
- REQ-006: 外部ライブラリを追加・使用しない。

## 入力

- Python の `str` を1つ受け取る。
- 空文字列を許可する。
- ASCII 以外の Unicode 文字を含んでよい。

## 出力

- 入力と同じ文字数の `str` を返す。
- ASCII 数字だけが `*` に置き換わり、それ以外は入力と同一の文字を同じ位置に保持する。

## エラー扱い

- この feature の仕様上の入力型は `str` のみとする。
- `str` 以外が渡された場合の型チェックや独自例外は今回の対象外とし、feature 内で追加しない。

## 今回やらないこと

- CLI entrypoint の作成・変更
- ファイル入力
- 正規表現パターンの利用者指定
- 置換文字の利用者指定
- ASCII 数字以外のマスキング
- 入力型チェックや独自例外
- 外部ライブラリ追加
- 共通化

## レビュー観点

- ASCII 数字だけが対象になっていること。
- 全角数字や Unicode 数字を誤って置換しないこと。
- 空文字列の扱いが明確であること。
- feature と CLI の責務が分離されていること。
- 下流工程で置換対象や例外方針を決める必要がないこと。

## 補足

実AIによる feature loop 再試験用の小さな feature です。
